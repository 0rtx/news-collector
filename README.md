# 实时快讯 · 重要消息

本地运行的财经快讯终端：按阅读量排名的“重要消息” + 新浪 7×24 快讯 + 收藏功能。

## 运行

双击 `start.bat`，或在命令行执行：

```powershell
python server.py
```

然后浏览器打开 <http://127.0.0.1:8000>。

服务仅依赖 Python 标准库，无需安装任何第三方包。

## 说明

- 重要消息：财联社电报，按阅读量降序展示，只保留近 24 小时内容（前 20 条）
- 7×24 快讯：新浪财经直播接口
- 每条消息右侧 ☆ 可收藏，收藏保存在浏览器 localStorage，可随时取消或清空
- 重要消息约每 60 秒刷新，快讯约每 30 秒刷新

> 免费公开接口可能存在延迟或波动，内容仅供信息参考，不构成投资建议。
